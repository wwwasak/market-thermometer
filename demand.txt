1) Business requirements (CN & US run independently; NO “total score”)

We need two independent thermometers: CN and US.
For each market we must support:

Indicators (main, in-scoring) and Observers (soft/hard confirm, NOT in-scoring)

Daily pipeline: compute daily Z & Score (0–100), daily regime (Attack / Balanced / Defense), and daily Final Lamp (Green / Yellow / Red).

Weekly pipeline: same logic, but reindexed to Friday (for weekly report).

GUI must allow switching daily/weekly views.

3) Standardization & scoring

Direction unify: Z = sign * (X - μ)/σ, where sign=+1 (up_good), -1 (down_good).

Z type:

Z(60): rolling mean/std (60 trading days)

MADZ(60/40/90): robust Z via median & MAD (1.4826 factor)

VIX: apply log then winsorize to 2%–98% before Z.

Score mapping: Score = clamp(50 + 10*Z, 0, 100)

4) Regime (per market, daily & weekly)

Thresholds: Attack ≥ 70, Defense ≤ 40, otherwise Balanced.

Crossing confirmation: daily view optional persistence_days=3 (default 0), weekly view persistence_weeks=1.

5) Confirm layer (per market, daily & weekly)

Single-lamp color from score: score ≥ 60 → Green, ≤ 40 → Red, else Yellow.

Hard veto combine: MIN (red wins) with persistence:

daily: persistence_days=3 (configurable)

weekly: persistence_weeks=2

Pair-combine rule (for CNH/CNY, TWEX/DXY) — Rule A (Consistency-first):

both Green → Green; both Red → Red; else Yellow.
(Provide Rule B as alternate in code: “strong divergence makes Red”)

Soft confirm weighted vote: map Green=2, Yellow=1, Red=0 → weighted average S

Thresholds: S ≥ 1.6 → Green; S ≤ 0.8 → Red; else Yellow.

Final Lamp: if HardVeto==Red → Red; else if SoftConfirm==Green → Green; else Yellow.

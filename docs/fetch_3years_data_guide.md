# 近三年数据获取与验证指南

## 📋 功能说明

`fetch_3years_data_and_verify.py` 脚本用于：

1. **获取近三年数据**：自动获取CN和US市场近三年（约1095天）的所有指标数据
2. **填充数据库**：将获取的数据经过转换、评分、确认层处理后存储到数据库
3. **验证需求符合性**：检查配置和计算逻辑是否符合`demand.txt`中的要求
4. **生成验证报告**：输出详细的验证报告，包括通过项、失败项和警告

## 🚀 使用方法

### 前置条件

1. **安装依赖**：
```powershell
pip install -r requirements.txt
```

2. **配置环境变量**（可选，如果需要FRED数据）：
```powershell
# 创建 .env 文件
echo "FRED_API_KEY=your_fred_api_key_here" > .env
```

### 运行脚本

```powershell
# 在项目根目录运行
python fetch_3years_data_and_verify.py
```

### 输出说明

脚本会输出以下内容：

1. **配置验证报告**：
   - ✓ 通过的检查项
   - ✗ 失败的检查项
   - ⚠ 警告信息

2. **数据获取进度**：
   - 每个市场的指标获取情况
   - 数据转换和评分计算进度
   - 数据库保存结果

3. **生成的文件**：
   - `data/market_thermo_3years.db` - 包含近三年数据的数据库
   - `data/verification_report.txt` - 详细的验证报告

## 📊 验证内容

脚本会验证以下内容是否符合`demand.txt`要求：

### 1. Regime阈值
- Attack阈值 = 70
- Defense阈值 = 40

### 2. 灯色阈值
- Green阈值 = 60
- Red阈值 = 40

### 3. 风格权重
- **CN市场**：
  - Attack: [24, 16, 12, 20, 16, 12]
  - Balanced: [20, 14, 12, 18, 18, 18]
  - Defense: [15, 10, 10, 12, 20, 33]
- **US市场**：
  - Attack: [12, 8, 18, 16, 16, 30]
  - Balanced: [15, 10, 20, 15, 20, 20]
  - Defense: [18, 12, 24, 18, 28, 0]

### 4. 软确认权重
- **CN市场**：PAIR_CNH_CNY=0.50, PAIR_TWEX_DXY=0.50
- **US市场**：IWM_SPY_SOFT=0.30, HYG_IEF_SOFT=0.30, PAIR_TWEX_DXY=0.20, PAIR_CNH_CNY=0.20

### 5. 持续性配置
- 周视图regime persistence = 1周
- 日视图硬否决persistence = 3天
- 周视图硬否决persistence = 2周

### 6. 转换参数
- EWMA lambda = 0.94
- VIX winsor = [0.02, 0.98]

### 7. 计算逻辑验证
- Score计算公式：`Score = clamp(50 + 10*Z, 0, 100)`
- Z分数方向统一：`Z = sign * (X - μ)/σ`，其中sign=+1 (up_good), -1 (down_good)

## ⚠️ 注意事项

1. **数据获取时间**：
   - 近三年数据获取可能需要较长时间（10-30分钟，取决于网络速度）
   - 建议在网络稳定的环境下运行

2. **CN市场数据**：
   - 部分CN市场数据需要CSV导入（如两融余额、北向成交占比等）
   - 如果CSV数据不可用，相关指标会显示为缺失

3. **数据完整性**：
   - 脚本会检查数据完整性，但不会强制要求所有数据都可用
   - 部分指标缺失不影响其他指标的计算

4. **数据库大小**：
   - 近三年数据可能产生较大的数据库文件（100-500MB）
   - 确保有足够的磁盘空间

## 🐛 故障排除

### 问题1：FRED API错误
```
[ERROR] FRED not initialized. Check API key.
```
**解决方案**：
- 检查`.env`文件中是否配置了`FRED_API_KEY`
- 或直接在代码中传入API key

### 问题2：yfinance数据获取失败
```
[ERROR] Failed to fetch data for ^VIX
```
**解决方案**：
- 检查网络连接
- yfinance可能需要更新：`pip install --upgrade yfinance`
- 某些数据源可能有访问限制，稍后重试

### 问题3：数据库锁定
```
[ERROR] database is locked
```
**解决方案**：
- 关闭其他正在使用数据库的程序
- 删除旧的数据库文件重新运行

### 问题4：配置验证失败
```
✗ Regime Attack阈值不匹配: 期望 70, 实际 75
```
**解决方案**：
- 检查`core/config.py`中的默认配置
- 确保配置值与`demand.txt`中的要求一致
